Entry for the [One Word for the Boss](https://make.fun/bounty/u-swift-badger-44-one-word-for-the-boss-6b48c735) bounty on make.fun.

The program writes exactly one word describing a boss — at most 30 characters — to `/output/entry.txt`. Nothing else is written; the word stands alone, with no trailing newline.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later (TypeScript is run as-is). The word is written to `/output/entry.txt` with no trailing newline.
